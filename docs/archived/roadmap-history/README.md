## File Naming Convention

- **Format:** `PHASE{X}_OR_{CATEGORY}_{STATUS}.md`
- **Status:** `COMPLETE`, `IN_PROGRESS`, `CANCELLED`
- **Date:** Include completion date in file header

## Accessing Historical Data

If you need detailed information about a completed phase:

1. Navigate to this directory: `docs/archived/roadmap-history/`
2. Open the relevant `*_COMPLETE.md` file
3. All original metrics, code samples, and notes are preserved

## Maintenance

- **When to archive:** When a major phase or milestone is 100% complete
- **What to include:** Full implementation details, metrics, lessons learned
- **What to exclude:** Future plans (keep those in main roadmap)
