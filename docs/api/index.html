🏗️ Arquitectura

  • Framework: Laravel 12 con nwidart/laravel-modules
  • API Standard: JSON:API 1.1 (strict compliance)
  • Autenticación: Laravel Sanctum con Bearer tokens
  • Autorización: Spatie Laravel Permission (roles granulares)
  • Base URL: http://localhost/api/v1

🔗 Arquitectura Contact Unificada

El sistema implementa una arquitectura Contact unificada donde:

  • Contact: Entidad central con flags is_customer y is_supplier
  • Finance Integration: APInvoice → Contact (suppliers), ARInvoice → Contact (customers)
  • GL Automation: Servicios automáticos de General Ledger integrados

Content-Type: application/vnd.api+json
Accept: application/vnd.api+json
