# Introduction

Modular Laravel 12 API with JSON:API 5.x specification for enterprise ERP/CRM applications.

<aside>
    <strong>Base URL</strong>: <code>http://localhost</code>
</aside>

    Welcome to the ERP API documentation. This API follows the **JSON:API 1.1 specification** and provides comprehensive endpoints for:

    - **Product Management** - Products, Categories, Brands, Units, Variants
    - **Inventory** - Warehouses, Stock, Batches, Movements, Cycle Counts
    - **Sales** - Orders, Shipments, Backorders, Discount Rules
    - **Purchase** - Suppliers, Purchase Orders
    - **Finance** - AR/AP Invoices, Payments, Bank Accounts
    - **Accounting** - Accounts, Journal Entries, Fiscal Periods
    - **HR** - Employees, Attendance, Payroll, Leave Management
    - **CRM** - Leads, Campaigns, Activities, Opportunities
    - **Ecommerce** - Carts, Checkout, Wishlists, Reviews
    - **Billing** - CFDI Invoices, PAC Integration

    <aside>All requests must include proper **Content-Type** and **Accept** headers: `application/vnd.api+json`</aside>
